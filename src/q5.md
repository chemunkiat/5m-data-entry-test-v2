**Format:** Short Answer

---

> Answer in your own words, 1-3 sentences each. Writing it yourself is the point.


**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
Kernel is a low level code - often in machine langauge that directly interact and manages a computer hardware including processor, memory, storage and input/output sub-systems. Kernel exposes formated interfaces to system services and software applications.

---

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
Not really accurate.
WSL is a virtual machine that reserved Windows systems and hardware resources including memory, storage, CPU, and created an environment separated from normal Windows applications within Windows OS, hence dual boot is not needed. 
Linux running in WSL as separated OS environment from Windows OS, but sharing system resources within the Windows OS.

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
terminal (emulator): provide the prompt for entering commands, and showing the output. E.g. Terminal in my Codespaces is the Terminal emulator
shell: is the command interpreter that execute command operations. E.g. Bash is the shell running in Terminal emulator
