**(c)** The SCTP course assumes a POSIX shell (bash or zsh). In your course material, you may encounter commands like these:

```bash
touch notes.txt
export API_KEY=abc123
chmod +x setup.sh
source venv/bin/activate
```

Give **one concrete reason** why running commands like these on Windows PowerShell can fail, even though some commands look similar to PowerShell at first glance. A general-knowledge answer is fine; you do not need to have used PowerShell yourself.

**Answer:**
@chemunkiat ➜ /workspaces/5m-data-entry-test-v2 (main) $ touch notes.txt
export API_KEY=abc123
chmod +x setup.sh
source venv/bin/activate
chmod: cannot access 'setup.sh': No such file or directory
bash: venv/bin/activate: No such file or directory

Windows PowerShell and POSIX shells such as Bash use different command syntax. For example, Bash uses export API_KEY=abc123 to define an environment variable, whereas PowerShell uses $env:API_KEY = "abc123". Therefore, directly executing Bash commands in PowerShell may fail because PowerShell does not recognise the same syntax. Vice versa for running PowerShell commands in Bash will fail too.
